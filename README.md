Overview

A practical QA engineering playbook for modern CI/CD environments. Covers Git workflows, branching strategies, test automation frameworks, API/UI testing, and search validation (OpenSearch). Focused on real-world engineering practices for scalable and maintainable QA systems.


📚 What's Inside

Git Workflows for QA Teams — branching strategies, isolating test changes, and safe collaboration in CI/CD-driven environments (./git-workflow-qa.md)

Linux Fundamentals for QA — command-line navigation, permissions, log analysis, and shell scripting for test and CI environments (./linux-for-qa.md)

Test Automation Frameworks — structuring maintainable, scalable automation suites

API & UI Testing — practical approaches to validating both service-level and user-facing behavior

Search Validation (OpenSearch) — testing and validating search relevance and indexing behavior
